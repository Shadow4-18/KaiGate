Lock

Production rules

2 s long-press toggles lock. Auto-relock after 10 s idle while stationary. Swipes die if speed is over 0.5 mph or a gear is in. Cold limiter holds the shift light at 3,500 RPM until coolant is 180 °F. Both values are live-tunable from the app.

Safety

Strobe and money-shift

Full-circle red/white flash, DRV2605L double-pulse, ES8311 beep. Money-shift compares predicted post-downshift RPM to redline using stored mph/rpm ratios. Idle mascot fades to /idle.gif after 30 s in neutral.

First drive

Bring-up

  1. Wire MPU-6050 and DRV2605L on I2C0 (GPIO 47/48). See HARDWARE.md.
  2. Fit a 1027 coin motor and a speaker on the MX1.25 header.
  3. Flash firmware. Serial should print CST820, MPU-6050, DRV2605L, ES8311.
  4. Pair Vgate iCar Pro with ignition on. Knob scans for Vgate / iCar / OBD.
  5. Open KaiGate, connect, run Calibrate in the driveway.
  6. Set redline and theme. Optional: Lens Studio → KaiGate_Setup → push idle GIF.
